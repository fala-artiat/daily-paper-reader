## 摘要
协作MSR码是一类存储码，能够以协作方式对任意 h≥2 个节点擦除进行最优带宽修复，同时保持作为 [n,k] MDS 码的最小存储。每个码坐标（节点）假设存储一个由 ℓ 个符号组成的阵列，其中 ℓ 称为子包化。为了解决磁盘 IO（输入/输出）能力问题，若在节点修复期间，每个帮助节点访问的数据量达到该量的下界，则称协作MSR码具有最优访问性质。本文关注降低最优访问协作MSR码的子包化水平。我们通过两种方法提出最优访问协作MSR码的新构造。首先，我们通过设计其奇偶校验矩阵提出一种直接显式构造。这样的奇偶校验矩阵通过反复使用两个关键奇偶校验矩阵作为构建模块来构建。其次，我们提出一个通用变换框架。从任意 [n+d-k,d] MDS 标量码出发，通过系统性地应用两种基本变换，可以得到最终的协作MSR码。两种方法都产生 (n,k,ℓ=δ^m) 最优访问协作MSR码，其中 δ=d-k+h，且 m=\binom{n}{h}-\lfloor\frac{n}{δ}\rfloor(\binom{δ}{h}-1)。与现有最优结果（其 ℓ=δ^{\binom{n}{h}}）相比，所得码可将子包化 ℓ 降低为原来的 1/δ^{\lfloor\frac{n}{δ}\rfloor(\binom{δ}{h}-1)}，其中 δ=d-k+h。此外，我们还表明，一些先前的最优访问协作MSR码结构以及 h=1 的最优访问MSR码结构，均作为我们变换构造的特例被包含在内。最后，我们指出，所有构造均建立在大小至少为 n+d-k 的有限域上。

## Abstract
Cooperative MSR codes are a kind of storage codes which enable optimal-bandwidth repair of any $h\geq2$ node erasures in a cooperative way, while retaining the minimum storage as an $[n,k]$ MDS code. Each code coordinate (node) is assumed to store an array of $\ell$ symbols, where $\ell$ is termed as sub-packetization. To address the disk IO (input/output) capability, a cooperative MSR code is said to have optimal-access property, if during node repair, the amount of data accessed at each helper node meets a lower bound on this quantity.   In this paper, we focus on reducing the sub-packetization level of optimal-access cooperative MSR codes. We propose new constructions of optimal-access cooperative MSR codes through two methods. At first, we propose a direct explicit construction by designing its parity-check matrix. Such parity-check matrix is built by repeatedly employing two crucial parity-check matrices as building blocks. Secondly, we propose a generic transformation framework. Starting from an arbitrary $[n+d-k,d]$ MDS scalar code, one can derive a final cooperative MSR code by systematically applying two basic transformations. Both approaches yield $(n,k,\ell=δ^m)$ optimal-access cooperative MSR codes with $δ=d-k+h$ and $m=\binom{n}{h}-\lfloor\frac{n}δ\rfloor(\binomδ{h}-1)$. Compared with the state of the art (with $\ell=δ^{\binom{n}{h}}$), the derived codes can reduce the sub-packetization $\ell$ by a fraction of $1/δ^{\lfloor\frac{n}δ\rfloor(\binomδ{h}-1)}$, where $δ=d-k+h$. Moreover, we also show that some previous code structures of optimal-access cooperative MSR codes and optimal-access MSR codes with $h=1$ are included as special cases of our transformation construction. At last, we note that all of the constructions are built over a finite field of linear size $\geq n+d-k$.

## 1. 核心问题与研究背景

- **应用背景**：大规模分布式存储系统（DSS）中节点失效频繁，纠删码被广泛用于数据保护。协作再生码允许在 **h ≥ 2 个节点同时失效**时，由 h 个新节点先从 d 个辅助节点下载数据、再相互交换数据完成协作修复，其中 **协作MSR码**在保持最小存储开销（等价于 [n,k] MDS 码）的同时达到最小修复带宽。
- **关键指标**：
  - **修复带宽** γ 与**访问数据量** γ_a 的下界分别为 (d+h−1)hℓ/(d−k+h) 与 dhℓ/(d−k+h)。
  - 当两者同时取等时，称该码具有 **最优访问（optimal-access）** 性质，可显著降低磁盘 I/O 开销。
- **核心痛点**：现有最优访问协作MSR码（如 Zhang-Zhang-Wang CL'2020、Li 等 ITW'2025）的子分组化 ℓ = (d−k+h)·C(n,h) = δ^{C(n,h)} 过大，导致实际编解码复杂度高、I/O 开销大。
- **本文目标**：在**保持 MDS 性质与最优访问性质**的前提下，尽可能**降低子分组化水平 ℓ**，并统一此前若干最优访问 MSR / 协作 MSR 码结构。

4. **统一性结论**：Zhang-Zhang-Wang CL'2020、Ye-Barg TIT'2017、Li-Tang-Tian TIT'2018 等结构均为本文变换构造的**特例**；奇偶校验矩阵构造亦可由变换法在 RS 型 MDS 标量码上导出。

## 8. 不足与局限

- **子分组化仍为指数级**：ℓ = δ^m 中 m 仍随 n、h 指数增长（如 n=7, h=3 时 m=26），实际系统中仍可能造成较高复杂度与 I/O 成本。
