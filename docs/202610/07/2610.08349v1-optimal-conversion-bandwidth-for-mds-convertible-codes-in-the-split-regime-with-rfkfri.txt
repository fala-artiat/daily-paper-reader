# Optimal Conversion Bandwidth for MDS Convertible Codes in the Split Regime with rF < k F < r I

Lewen Wang Sihuang Hu ∗

Abstract 

Erasure codes are widely used in distributed storage systems to provide fault tolerance. An [n, k ] erasure code encodes k data symbols into n coded symbols and distributes them across n

storage nodes. Once the code parameters are fixed, the achievable fault tolerance is also fixed. However, the failure rates of storage nodes may vary over time, and dynamically adapting the code parameters to these variations can substantially reduce storage overhead. Motivated by this observation, Maturana and Rashmi introduced convertible codes, which allow an [ nI , k I ]initial code with redundancy rI = nI − kI to be transformed into an [ nF , k F ] final code with redundancy rF = nF − kF , while preserving the required code properties. Convertible codes whose initial and final codes are both MDS codes are called MDS convertible codes. They are of particular interest because MDS codes provide the maximum erasure tolerance for a given amount of storage overhead. Several works have established lower bounds and constructions for the bandwidth cost of MDS convertible codes in the split regime. However, the tight bound in the parameter range 

rF < k F < r I remains unknown. In this work, we establish a family of new rank inequalities for stable MDS convertible codes with linear conversion procedures and derive an improved lower bound on the bandwidth cost consisting of three cases for this remaining range. We prove that the bound is tight by presenting three explicit constructions, one for each case. 

# 1 Introduction 

Erasure coding has become a fundamental technique for protecting data against device failures in distributed storage systems. In this setting, an [ n, k ] erasure code over a finite field Fq encodes 

k data symbols into n coded symbols, which are then stored on n distinct storage nodes. Once the code parameters n and k are fixed, the fault-tolerance capability of the system is also fixed. In practice, however, the failure rates of storage devices may vary over time. In particular, the failure rate may follow a bathtub curve over the device lifetime. It is relatively high during an early-failure period, becomes lower and relatively stable during the useful-life period, and increases again during the wear-out period. Prior work by Kadekodi et al. has shown that adapting the code parameters to changes in device reliability can substantially reduce storage overhead while maintaining a prescribed reliability level [1]. Therefore, it is desirable to dynamically adjust the code parameters as the fault-tolerance requirements of the system change. A straightforward approach is to decode and re-encode all stored data, which incurs significant I/O and communication costs. To reduce these costs, Maturana and Rashmi introduced the framework of convertible codes , which enables efficient conversion from an initial code to a final code with different parameters while preserving desired code properties [2–4]. When additional

In particular, MDS codes are of special interest due to their widespread use in distributed storage and their optimal erasure tolerance. A convertible code whose initial and final codes are both MDS codes is called an MDS convertible code . The framework has subsequently been extended to other classes of codes, including locally repairable codes [5–7] and minimum storage regenerating(MSR) codes [8]. There are two basic regimes in code conversion. The first is the merge regime , where several initial codewords are converted into a single final codeword. The second is the split regime , where one initial codeword is converted into several final codewords. These two regimes serve as fundamental building blocks for more general code conversions. The efficiency of code conversion is commonly measured by two metrics. The first is the access cost , namely, the total amount of store data accessed during conversion. Maturana and Rashmi established fundamental lower bounds on the access cost of MDS convertible codes and provided optimal constructions for both the merge and split regimes [2, 3, 9]. Subsequent work studied, among other directions, low-field-size constructions [10], irregular and generalized conversions [11–13], and extensions to locally repairable and regenerating codes [5–8, 14]. The second metric is the bandwidth cost , namely, the amount of data transferred during conversion. For the merge regime, Maturana and Rashmi established a tight lower bound and constructed optimal MDS convertible codes achieving this bound [15]. Recent work has extended the study of the merge regime to more general code settings and constructions [11–13, 16, 17]. In contrast, the bandwidth problem in the split regime remains less understood. Maturana and Rashmi derived an information-flow lower bound and proposed explicit constructions based on the piggybacking framework [18]. Their results characterize the optimal bandwidth when rF ≥ kF or rI ≤ rF . For the remaining range, their stronger bound relies on an additional conjecture. More recently, Wang and Hu [19] and Singhvi et al. [20] improved the bandwidth lower bounds using algebraic and information-theoretic approaches, respectively. Both works established tight bounds when rF ≥ kF

or rI ≤ kF . However, the tightness of the lower bounds for rF < k F < r I remained open. In this paper, we resolve the remaining regime rF < k F < r I for stable MDS convertible codes with linear conversion procedures. We strengthen the lower bound in this regime and provide explicit constructions attaining the resulting bounds. Our main contributions are summarized as follows. 

• An improved lower bound for rF < k F < r I . Building on coordinate projections of the associated column spaces of the initial and final codes, we derive a family of rank inequalities for the read bandwidth from unchanged and retired nodes. These inequalities include the constraints used in [19] as special cases. In particular, when rF < k F and rI ≤ kF , all additional inequalities are redundant, and the resulting linear program reduces to the two constraints used in [19]. Hence, it recovers the previous lower bound in this regime, which is tight as it is matched by the constructions of Maturana and Rashmi [18]. For the remaining range rF < k F < r I , the new inequalities impose additional constraints that strengthen the lower bound. By solving the resulting linear program, we obtain an improved lower bound on the read bandwidth for the remaining range rF < k F < r I . The bound consists of three cases and is formally stated in Theorem 1. 

• Explicit constructions for the three cases. We provide three explicit constructions corresponding to the three cases of the lower bound. For Cases I and II, we select suitable rows of the final parity matrix, referred to as anchor rows , and use an invertible transformation to map the corresponding anchor-row matrix to a Cauchy submatrix of the initial parity matrix. This simultaneously yields the required column-space relation for conversion and ensures the MDS property. For Case III, we construct a two-layer auxiliary MDS array code: the first 2layer is based on structured polynomial evaluations, while the second layer is based on a Reed–Solomon code. This realizes the required column-space inclusion while preserving the MDS property. 

• Tightness in the stable linear conversion model. The three constructions attain the corresponding lower bounds whenever the required integrality conditions are satisfied. These conditions can always be met by choosing the subpacketization ℓ appropriately, with 

ℓ polynomial in the initial code length nI . Cases I and II can be realized over fields of size

Since the write bandwidth is fixed for stable conversion, this also determines the minimum total conversion bandwidth in this regime. The remainder of this paper is organized as follows. Section 2 introduces the necessary definitions and notation. Section 3 derives improved lower bounds on the read bandwidth for the regime 

rF < k F < r I . Section 4 presents explicit constructions attaining these lower bounds and analyzes their field-size and subpacketization requirements. Finally, Section 5 concludes the paper.

# 5 Conclusion 

In this paper, we studied the bandwidth cost of stable MDS convertible codes with linear conversion procedures in the split regime for the remaining parameter range rF < k F < r I .

By considering coordinate projections of the associated column spaces of the initial and final codes onto different groups of coordinates, we derive a family of rank inequalities involving the amounts of data read from the unchanged and retired nodes. These inequalities recover the previous lower bounds for the regime rI ≤ kF with rF < k F . When rF < k F < r I , the inequalities impose further constraints that strengthen the resulting lower bound. By solving the corresponding linear program, we obtain an improved lower bound for this remaining regime, consisting of three cases. To establish the tightness of the lower bound, we presented three explicit constructions. The constructions for Cases I and II are based on selecting suitable anchor rows of the final parity matrix, and choosing an invertible transformation that maps the corresponding anchor-row matrix to a Cauchy submatrix of the initial parity matrix. This yields the required column-space relation for conversion, while the resulting Cauchy structure guarantees the MDS property. For Case III, to realize the required column-space inclusion for conversion while preserving the MDS property, we construct an auxiliary MDS array code with two layers: the first layer is based on structured polynomial evaluations, and the second layer is based on a Reed–Solomon code. The three constructions attain the corresponding lower bounds. The required integrality conditions can always be satisfied by choosing the subpacketization ℓ appropriately, with ℓ polynomial in the the initial code length nI .The constructions for Cases I and II can be realized over fields of size q = O (kI + rI )ℓ, whereas for Case III it suffices to take q = O (( kI + rI )ℓ)L0

 for some absolute constant L0. Consequently, our lower bound is tight throughout the regime rF < k F < r I within the stable linear conversion model. Since the write bandwidth is fixed for stable conversion, our results determine the minimum total conversion bandwidth in this regime. Several questions remain for future work. It would be desirable to reduce the field size required by all three constructions to be linear in the code length. Another direction is to determine the exact optimum for a prescribed subpacketization when the LP-optimal read amounts are nonintegral, without enlarging ℓ.19 References
