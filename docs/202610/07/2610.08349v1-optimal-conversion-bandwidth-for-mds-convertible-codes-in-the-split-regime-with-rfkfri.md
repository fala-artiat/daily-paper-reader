## 摘要
纠删码被广泛用于分布式存储系统以提供容错能力。一个 $[n,k]$ 纠删码将 $k$ 个数据符号编码为 $n$ 个编码符号，并将它们分布在 $n$ 个存储节点上。一旦码参数固定，可实现的容错能力也随之固定。然而，存储节点的故障率可能随时间变化，动态地调整码参数以适应这些变化可以显著降低存储开销。受此观察启发，Maturana 和 Rashmi 提出了可转换码，它允许将具有冗余度 $r^I=n^I-k^I$ 的 $[n^I,k^I]$ 初始码转换为具有冗余度 $r^F=n^F-k^F$ 的 $[n^F,k^F]$ 最终码，同时保持所需的码性质。初始码和最终码均为 MDS 码的可转换码称为 MDS 可转换码。它们尤其受到关注，因为对于给定的存储开销，MDS 码能提供最大的擦除容忍能力。已有若干工作为分裂情形下 MDS 可转换码的带宽开销建立了下界和构造。然而，在参数范围 $r^F<k^F<r^I$ 内，紧界仍然未知。在这项工作中，我们为具有线性转换过程的稳定 MDS 可转换码建立了一族新的秩不等式，并针对这一剩余范围推导出一个改进的带宽开销下界，该下界包含三种情形。我们通过给出三个显式构造（每种情形一个）证明了该界是紧的。

## Abstract
Erasure codes are widely used in distributed storage systems to provide fault tolerance. An $[n,k]$ erasure code encodes $k$ data symbols into $n$ coded symbols and distributes them across $n$ storage nodes. Once the code parameters are fixed, the achievable fault tolerance is also fixed. However, the failure rates of storage nodes may vary over time, and dynamically adapting the code parameters to these variations can substantially reduce storage overhead. Motivated by this observation, Maturana and Rashmi introduced convertible codes, which allow an $[n^I,k^I]$ initial code with redundancy $r^I=n^I-k^I$ to be transformed into an $[n^F,k^F]$ final code with redundancy $r^F=n^F-k^F$, while preserving the required code properties. Convertible codes whose initial and final codes are both MDS codes are called MDS convertible codes. They are of particular interest because MDS codes provide the maximum erasure tolerance for a given amount of storage overhead.   Several works have established lower bounds and constructions for the bandwidth cost of MDS convertible codes in the split regime. However, the tight bound in the parameter range $r^F<k^F<r^I$ remains unknown. In this work, we establish a family of new rank inequalities for stable MDS convertible codes with linear conversion procedures and derive an improved lower bound on the bandwidth cost consisting of three cases for this remaining range. We prove that the bound is tight by presenting three explicit constructions, one for each case.

## 1. 核心问题与整体含义（研究动机与背景）

- **应用背景**：分布式存储系统广泛使用纠删码提供容错。$[n,k]$ 纠删码把 $k$ 个数据符号编码为 $n$ 个编码符号分布于 $n$ 个节点，但码参数一旦固定，容错能力也随之固定。
- **现实矛盾**：存储设备失效率随时间变化（早期失效期高、有效寿命期低、磨损期再升高，即"浴盆曲线"）。Kadekodi 等人的工作表明，按设备可靠性动态调整码参数可在维持目标可靠性前提下显著降低存储开销。
- **已有框架**：Maturana 与 Rashmi 提出**可转换码（convertible codes）**，允许把冗余为 $r^I=n^I-k^I$ 的初始码转换为冗余为 $r^F=n^F-k^F$ 的最终码，同时保持码性质。初始码与最终码均为 MDS 码者称为 **MDS 可转换码**，因 MDS 码在给定存储开销下擦除容忍能力最大而尤为重要。
- **两种基本转换机制**：**合并（merge）** 机制（多个初始码字→单个最终码字）与**分裂（split）** 机制（一个初始码字→多个最终码字）。效率度量有两个：**访问开销（access cost）** 与**带宽开销（bandwidth cost）**。
- **研究缺口**：合并机制的带宽紧界与最优构造已建立；分裂机制中，已有工作（Maturana–Rashmi 的 piggybacking 构造、Wang–Hu 的代数下界、Singhvi 等人的信息论下界）仅在 $r^F\ge k^F$ 或 $r^I\le k^F$ 时给出紧界。**剩余区间 $r^F<k^F<r^I$ 的带宽紧界一直未知**。
- **本文定位**：针对**具有线性转换过程的稳定（stable）MDS 可转换码**，在分裂机制下彻底解决 $r^F<k^F<r^I$ 这一剩余区间，给出改进下界（三种情形）并用三种显式构造证明其可达（紧性）。

## 2. 方法论：核心思想与关键技术细节

### 2.1 问题设定与规范化表示

- 稳定转换意味着使用最大数量的不变（unchanged）符号：恰有 $k^I$ 个不变符号，每个最终码字含 $k^F$ 个不变符号与 $r^F$ 个新符号，故写带宽固定为 $W=\lambda r^F\ell$，**最小化总带宽等价于最小化读带宽 $R$**。
- **引理 1（系统化表示）**：经节点置换与消息坐标的可逆变换，可写
  - 初始码：$G_I=[I_{k^I\ell}\mid B]$
  - 最终码：$G_{F_t}=[I_{k^F\ell}\mid C_t]$
  且 $B$、$C_t$ 均为**块超正则（block superregular）**：任意方形块子矩阵非奇异。
- 定义 $x=\sum_{i=0}^{k^I-1}\beta_i$（从不变符号读出的数据量）、$y=\sum_{i=k^I}^{n^I-1}\beta_i$（从退役符号读出的数据量），故 $R=x+y$。
- **引理 2（线性转换刻画）**：存在线性稳定转换当且仅当 $\mathrm{col}(\widetilde{C})\subseteq\mathrm{col}(\widetilde{B})$；此时读带宽为 $x+\mathrm{rank}(\widetilde{B})$，最优时可设 $\widetilde{B}$ 满列秩。

### 2.2 核心思想：坐标投影 + 秩不等式族

- **第一步（对角块秩下界）**：利用 $C_t$ 的块超正则性，对任意 $|U|=r^F$ 的子集 $U\subseteq[k^F]$，删除被读取行最多降低秩 $\sum_{i\in U}\beta_{tk^F+i}$，平均后得 $\mathrm{rank}(C^{(t)})\ge r^F\ell-\frac{r^F}{k^F}x_t$，求和得
  $$\mathrm{rank}(\widetilde{C})\ \ge\ \lambda r^F\ell-\frac{r^F}{k^F}x.$$
- **第二步（关键创新——坐标投影）**：对每组 $s\in[\lambda]$ 取 $S\subseteq[\lambda]$，$|S|=s$，令 $I_S$ 为对应不变块行索引集合，$\pi_S$ 为保留 $I_S$ 块行的坐标投影。由 $\mathrm{col}(\widetilde{C})\subseteq\mathrm{col}(\widetilde{B})$ 得 $\mathrm{col}(\widetilde{C})\cap\ker\pi_S\subseteq\mathrm{col}(\widetilde{B})\cap\ker\pi_S$，用秩–零度定理推出
  $$\mathrm{rank}(\widetilde{B}_S)-\mathrm{rank}(\widetilde{C}_S)\le y-\mathrm{rank}(\widetilde{C}).$$
  同时用块超正则性对 $\mathrm{rank}(\widetilde{B}_S)$ 做下界估计（对 $q_s$-子集 $J\subseteq[r^I]$ 与 $H\subseteq I_S$ 求和平均），$q_s=\min\{sk^F,r^I\}$，得 $\mathrm{rank}(\widetilde{B}_S)\ge \frac{q_s}{r^I}y-\frac{q_s}{sk^F}x_S$。
- **引理 4（秩不等式族）**：合并上述两式并对所有 $|S|=s$ 平均，得到对每个 $s\in[\lambda]$：
  $$\frac{q_s+(\lambda-s)r^F}{k^I}x+\Bigl(1-\frac{q_s}{r^I}\Bigr)y\ \ge\ (\lambda-s)r^F\ell.$$
  - 该不等式族**包含文献 [19] 的约束作为特例**：当 $r^I\le k^F$ 且 $r^F<k^F$ 时，$s\ge2$ 的约束冗余，LP 退化为 [19] 的两条约束，从而复现已有紧界。
  - 在 $r^F<k^F<r^I$ 时，$s\ge2$ 的约束是**新增的、真正起作用**的约束，可加强下界。
  - **注记 2**：证明只依赖各 $C_t$ 的块超正则性，不要求各最终码相同或等价，故不等式族对"一个初始码→$\lambda$ 个不同最终 MDS 阵列码"的稳定线性转换同样成立。

### 2.3 线性规划求解与主定理

- 求解 LP：$\min R=x+y$，约束为引理 4 全部不等式及 $0\le x\le k^I\ell$、$0\le y\le r^I\ell$。
- 定义参数：$m=\bigl\lfloor\frac{r^I-1}{k^F}\bigr\rfloor$，$\delta=r^I-mk^F$，$h=\lambda-m$，$\Delta=r^I(k^F-r^F)+k^Ir^F$，$T=r^I+(h-1)r^F$，$\Gamma=\frac{r^I(mk^F+hr^F)}{k^I\delta}$。
- **定理 1（改进下界，三种情形）**：
  1. 若 $k^I\le r^I$：$R\ge \lambda r^F\ell$；
  2. 若 $k^I>r^I$ 且 $\Gamma\ge1$：$R\ge \frac{(k^I)^2r^F}{\Delta}\ell$；
  3. 若 $k^I>r^I$ 且 $\Gamma<1$：$R\ge\Bigl(\frac{k^I(h-1)r^F}{T}+\frac{r^Ir^F(mk^F+h\delta)}{\delta T}\Bigr)\ell$。
- **几何直观**：约束等值线 $\phi_s(x)$ 的斜率严格递减（$\gamma_0>\gamma_1>\cdots>\gamma_m$）且共点 $P=(x_{\text{int}},y_{\text{int}})$，故有效约束包络为分段折线；当 $\Gamma\ge1$ 时最优点为 $P$（对应情形 2），当 $\Gamma<1$ 时最优点为最左可行点 $Q=(x_v,y_v)$（对应情形 3）。
- **注记 3**：证明同时给出 LP 最优解 $(x^*,y^*)$，直接指导第 4 节的匹配构造。

### 2.4 三种显式构造（紧性证明）

- 统一设定：各构造中 $\lambda$ 个最终码字共用同一 $G_F=[I_{k^F\ell}\mid C]$，并令 $\ell$ 适当选取以保证读取子符号数为整数。
- **情形 I（$r^I\ge k^I$，$R=\lambda r^F\ell$）**：
  - 只从退役校验节点读取 $\sigma=\lambda r^F\ell/r^I$ 个子符号，不读任何系统子符号（$\beta=0$）。
  - 取 $C$ 为标量 Cauchy 矩阵分块；取每个 $C_i$ 的前 $\sigma$ 行为**锚行（anchor rows）**得 $A_0$，其余行为 $M_0$；令 $A=I_\lambda\otimes A_0$、$M=I_\lambda\otimes M_0$、$F=I_\lambda\otimes C$。
  - 构造标量 Cauchy 矩阵 $E$，将 $A$、$E$ 的行分别补成基得可逆矩阵 $\hat A$、$\hat E$，取 $L=\hat A^{-1}\hat E$ 使 $AL=E$；令 $Z=ML$、$D=FL$。
  - 再用 Cauchy 矩阵 $Q$ 拼出**块三角结构** $B_{i,j}=\begin{bmatrix}E_{i,j}&0\\ Z_{i,j}&Q_{i,j}\end{bmatrix}$，保证块超正则（MDS）。
  - 转换条件：$\widetilde{C}=F$，$\widetilde{B}=D=FL$，$L$ 可逆 $\Rightarrow\mathrm{col}(\widetilde C)=\mathrm{col}(\widetilde B)$。
- **情形 II（$k^F<r^I<k^I$，$\Gamma\ge1$）**：
  - 读参数：$\beta=\frac{r^F(k^I-r^I)}{\Delta}\ell$（每个不变系统节点），$\sigma=\frac{k^Ir^F}{\Delta}\ell$（每个退役校验节点）。
  - 取 $N$ 为标量 Cauchy 矩阵，$\hat C=N\otimes I_\ell$；限制到前 $u$ 行得 $H=N\otimes I_u$；用**模 $u$ 循环选取锚行** $S_i=\{iw,\dots,(i+1)w-1\}\bmod u$ 得 $A_0$，补集 $S_i$ 得 $M_0$。

  - 用行置换 $\Pi$ 把每个系统块重排为"锚行 / 被读行 / 其余未读行"，得 $C=\Pi\hat C$，仍块超正则。
